## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| **LangChain** | Framework for building LLM applications |
| **LangGraph** | Workflow orchestration & state management |
| **LangSmith** | Observability, evaluation & prompt engineering |
| **OpenRouter** | Unified API for LLM providers |

---

## 🚀 Getting Started
```bash
pip install langchain langchain-openai langgraph langsmith
```
```bash
OPENROUTER_API_KEY=your_key
LANGSMITH_API_KEY=your_key
```

## 📖 Key Concepts

| Concept | Description |
|---------|-------------|
| **Agent** | LLM + Tools — reasons and acts autonomously |
| **RAG** | Retrieves from your documents before answering |
| **Multi-Agents** | Specialized agents coordinated by a supervisor |
| **LangSmith** | Visibility into every step your agent takes |
